# Projet de Recettes

## Description
Application web de gestion de recettes culinaires.

## Configuration
1. Cloner le projet dans un répertoire
2. Installer les dépendances :
   ```bash
   npm install
   ```

## Dépendances principales
- Express.js : Framework web Node.js
- Dépendances listées dans package.json

## Démarrage
```bash
npm start
```

## Tests
```bash
npm test
```

## Audit de sécurité
```bash
npm audit
```

## Structure du projet
